# NEST-CRAFT Geometry Quality Assurance Skill

Use this skill whenever authoring, refactoring, evaluating, or auditing geometry engine code, polygon clipping, collision detection, CAD entity parsing, or packing algorithms in NEST-CRAFT.

## Core Geometric Invariants

Every nesting solution generated by NEST-CRAFT must satisfy the following mathematical and manufacturing invariants:

1. **Zero Pairwise Overlap (Hard Constraint):**
   - For every pair of distinct placed parts $P_i, P_j$ on any sheet ($i \neq j$):
     $$\text{Area}(P_i \cap P_j) = 0.0000\text{ mm}^2$$
   - A single point or linear boundary touch is acceptable if and only if clearance $c = 0.0$, but forbidden when clearance $c > 0.0$.

2. **Strict Kerf Clearance ($c > 0$):**
   - Minimum separation between any two external boundaries:
     $$\text{dist}(P_i, P_j) \ge c$$
   - In Shapely implementation: `P_i.buffer(c / 2).intersects(P_j.buffer(c / 2))` must be `False`.

3. **Stock Boundary Containment:**
   - Every part $P_i$ must reside strictly within the usable stock plate boundary $S$:
     $$P_i \subset S \iff S.\text{contains}(P_i)$$
   - When margin $m > 0$ is specified:
     $$P_i \subset S.\text{buffer}(-m)$$

4. **Part-in-Part Inward-Buffered Feasibility ($H \ominus \mathcal{B}_c$):**
   - When a part $C$ is placed inside an interior hole $H$ of parent part $P$:
     $$H_{\text{feas}} = H.\text{buffer}(-c)$$
   - $C$ must be completely contained within $H_{\text{feas}}$:
     $$C \subset H_{\text{feas}} \iff H_{\text{feas}}.\text{contains}(C)$$
   - This guarantees that $\text{dist}(C, \partial H) \ge c$ and that $C$ never collides with the solid body of $P$.

5. **Topological Hierarchy & Hole Extraction:**
   - When parsing DXF drawings, contours must be topologically classified by containment depth:
     - Depth 0 (Even) = Exterior Part Boundary
     - Depth 1 (Odd) = Interior Cutout / Hole
     - Depth 2 (Even) = Island / Nested Contour inside Hole
   - Holes must never be flattened or discarded.
